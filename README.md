本项目用于训练基于深度学习的钢筋混凝土梁-柱子结构连续倒塌抗力预测模型。模型采用图像-文本混合输入方式，将结构几何参数、材料参数、配筋信息和边界刚度信息作为输入，用于预测柱失效工况下结构的荷载-位移响应特征点。

1. 项目简介
  本项目主要包括：
  数据集文件
  特征图像数据
  模型训练代码
  模型验证与测试代码
  训练完成后的模型权重文件

  模型输入包括结构参数和对应的特征图像，输出为荷载-位移曲线上的关键特征点，例如屈服点、峰值点、转换点和倒塌点。

2. 输入参数
  输入参数文件为 parameters_**.txt
  每一行代表一个样本，每一列代表一个结构参数，
  从第2列至17列分别为：长跨长度，短跨长度，长跨梁高，长跨梁宽、短跨梁高、短跨梁宽，混凝土圆柱体抗压强度，长跨梁底配筋面积，长跨梁顶配筋面积，短跨梁底配筋面积，
                      短跨梁顶配筋面积，4个边界刚度，长跨钢筋中心至混凝土表面距离，短跨钢筋中心至混凝土表面距离。
  第1列和第18列均为0.2倍短跨长度，不参与特征图绘制，也不作为输入参数。

3. 标签文件
  标签文件为 labels_**.txt
  每一行对应一个样本的输出结果。标签可以包括荷载-位移曲线上的四个关键点：x1,y1,x2,y2,x3,y3,x4,y4
  其中：
  (x1, y1)：屈服点
  (x2, y2)：峰值点
  (x3, y3)：转换点
  (x4, y4)：倒塌点
